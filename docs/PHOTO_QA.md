# Этап 2.3: проверка на Android-устройстве

APK: artifact `app-debug` успешного Android build ветки `feature/photo-detection-ui`.
Локально: `app/build/outputs/apk/debug/app-debug.apk` после сборки по README.
Устанавливать поверх существующей версии можно при совпадении debug-подписи; если подпись отличается,
использовать одну и ту же сборочную среду или удалить прежнюю тестовую установку.

## Ручная проверка
1. Установить APK, открыть «Фото». Запроса доступа ко всей галерее или камере в этом режиме быть не должно.
2. Нажать «Выбрать фото», отменить picker: приложение не должно менять текущий снимок/результат или зависать.
3. Выбрать реальное фото дрона → «Распознать». Проверить изображение, рамки с confidence, список номеров и время в мс. Результаты зависят от модели: наличие дрона не гарантирует обнаружение.
4. Повторить с портретным, горизонтальным и панорамным фото; включая JPEG с EXIF-поворотом/отражением. Повернуть телефон до/во время/после распознавания: фото остаётся upright, рамки не смещаются.
5. На снимке, для которого модель вернула пустой результат, проверить «Дроны не обнаружены», время и отсутствие старых рамок. Негативный снимок сам по себе не гарантирует пустой ответ модели.
6. Нажать «Повторить». Во время загрузки/инференса выбрать другой снимок, затем ещё один: должны отображаться только последнее выбранное фото и его результаты.
7. Открыть крупный снимок (например, 48 Мп), а также прозрачный PNG. Проверить отсутствие краша/повреждения изображения. Обработка использует уменьшенную копию до 2048 px, PNG композитится на чёрный фон.
8. Переключиться в «Камера», разрешить CAMERA: проверить прежнее превью, фон/возврат. Вернуться в «Фото»: снимок и результаты сохраняются. Закрыть приложение: ресурсы модели освобождаются после завершения текущего нативного вызова.
9. По возможности повторить на API 26/27 (fallback системного выбора файла + BitmapFactory) и API 28+ (ImageDecoder); Android 13+ — системный Photo Picker.

## Автоматические проверки
```bash
./gradlew assembleDebug assembleDebugAndroidTest testDebugUnitTest lintDebug
python3 ml/scripts/verify_apk_model.py app/build/outputs/apk/debug/app-debug.apk
# Только с подключённым Android-устройством/эмулятором:
./gradlew connectedDebugAndroidTest
```

Device-тесты `PhotoDecoderInstrumentedTest` проверяют реальные Android-кодеки: 8 EXIF-ориентаций,
ограничение размера, прозрачность, повреждённый файл и путь decoded photo → настоящий ORT.
Их компиляция не равна прохождению на устройстве. JVM-тесты проверяют геометрию Fit, состояния,
пустые результаты, ошибки, повторный выбор, устаревшие ответы и освобождение backend после закрытия.

## Известные ограничения
- Качество детектора и ложные срабатывания прежние; модель и датасет не менялись, см. RESEARCH.md.
- Нет zoom/pan, видеоинференса, SAHI, трекинга и сохранения результатов. Выбранный снимок хранится только в памяти процесса.
- Нативный инференс не прерывается посередине. Новый запрос ждёт его окончания; старый результат/ошибка отбрасываются. Очередь ограничена последним запросом.
- Проверка удобства UI, Android-кодеков и времени на конкретном телефоне требует выполнения этого чек-листа на устройстве.
