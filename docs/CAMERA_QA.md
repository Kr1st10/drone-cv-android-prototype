# Проверка камер — этап 6.1

Автоматическая сборка и эмулятор не подтверждают работу конкретного объектива. Xiaomi 17T Pro, Xiaomi 17 Pro и Realme 11 Pro необходимо проверить физически. Никакие Camera ID не зашиты: их выдаёт Android. Поддержка физических потоков зависит от ОС, устройства и набора use cases. Инвентаризация описывает доступные API данные; заявленные производителем характеристики и zoom 5× не доказывают использование оптического телевика.

1. Установите debug APK из Actions PR (`app-debug`), откройте «Камера», предоставьте разрешение. При конфликте подписи обновить существующее приложение не получится: удаление старой версии удаляет данные. Перед проверкой сохраните необходимые отчёты.
2. В прокручиваемой панели нажмите «Обновить список камер», сохраните «Экспорт камер JSON» через системный диалог. JSON содержит Camera2 ID, физические ID, фокусные расстояния, размеры поддерживаемых выходов, возможности логической мультикамеры, диапазоны зума и доступные CameraX ID; значения, не выданные системой, не интерпретируются как отсутствие аппаратного модуля. При ошибке сохраните её текст.
3. На неподвижной сцене с хорошо заметным удалённым ориентиром выберите 1× и дождитесь кадра, запишите отображаемые логический и активный физический ID, zoomRatio и размеры объекта в кадре. Запустите детекцию и проверьте совмещение рамки с объектом в центре и у краёв (используйте настоящую размеченную цель; модель может пропустить её). Старыe рамки после переключения должны исчезнуть.
4. Нажмите 5×, дождитесь окончания перепривязки и новых кадров. Повторите измерение размера ориентира в пикселях и совмещения рамок; используйте ту же позицию, ориентацию, освещение и размер кадра. Соотношение размеров подтверждает масштаб изображения, но не оптику: цифровой crop тоже увеличивает объект.
5. Если система сообщает активный физический ID, сравните его при 1× и 5× с метаданными физических камер и их фокусными расстояниями. Смена ID в сочетании с характеристиками — свидетельство переключения сенсора; не называйте его телевиком без достаточных данных. Если ID отсутствует или совпадает, тип использованного увеличения программно не подтверждён. Сохраните отдельный JSON после каждого режима; перечисленные характеристики снимаются при обновлении, а текущие параметры — при экспорте.
6. Если показаны физические ID, поочерёдно запросите подходящий по фокусному расстоянию ID. Это запрос, а не доказательство поддержки: CameraX/устройство могут отказать для сочетания Preview + Analysis. Проверьте предупреждение, корректный возврат к 1× и повторный запуск. Нажмите 1× для возврата к автоматической задней камере. Не делайте вывод об оптике только по отсутствию ошибки. `active_physical_id` относится к логическому потоку; для принудительно выбранных физических выходов он сам по себе не подтверждает источник каждого потока.
7. Проверьте поворот, фон/возврат, Stop/restart, повторное переключение и занятую/недоступную камеру. Убедитесь, что диагностическая сессия при смене камеры прерывается, а поздние результаты прежнего кадра не появляются. Повторите на Xiaomi 17 Pro и отдельно на Realme 11 Pro; сохраните JSON, версию APK, снимки экрана с разрешения пользователя, результаты и ограничения. Фотографии и видеокадры приложением не сохраняются.

Оценка рамок на движущейся цели затруднена задержкой инференса. CameraX может не предоставлять счётчик пропущенных кадров, а некоторые реализации не сообщают активный физический ID. Аппаратный выбор, геометрия и стабильность требуют реальной проверки; сам факт успешной сборки этого не подтверждает.
