# Этап 4.3 — внешняя оценка

Рабочее исследование. Никаких метрик и утверждений о независимости до проверки данных.

## Кандидаты

- [AOD 4](https://data.mendeley.com/datasets/cd5z895tr2/1), DOI 10.17632/cd5z895tr2.1, заявлена CC BY 4.0. [Статья](https://pmc.ncbi.nlm.nih.gov/articles/PMC11372627/) описывает изображения/рамки дронов, птиц, самолётов и null; источники включают Anti-UAV, YouTube-8M и Roboflow. Общее происхождение YouTube требует проверки на пересечения с обучающим pathikg; размер и состав доступного архива ещё проверяются.
- [Anti-UAV](https://github.com/zsx060/Anti-UAV-datasets): RGB-видео в версии 300, разметка покадровая. MIT указан для проекта; права на данные требуется проверять отдельно. 410/600 содержат IR, непригодный для прямого сравнения RGB-модели. Если используются видео, фиксировать последовательности и разнос кадров.
- [YOLOBirDrone](https://www.csio.res.in/CommonNew.php?ds=401&page=1): научное использование разрешено, публичное распространение без разрешения запрещено; полный набор предоставляется по запросу, доступен пробный архив. Никакие изображения или разметку не публиковать.

## План

Использовать прежние веса YOLO11s и 640/960/SAHI416; одинаковая разметка и конфигурация, раздельный учёт ошибок птиц и самолётов. Без данных не публиковать фиктивные показатели. Ветку не объединять автоматически.
