# Этап 4.5 — подготовка данных, воспроизведение и ограничения

Это инфраструктура для будущей проверки, а не обучение или новый эксперимент качества. Политика оценки — [PROTOCOL.md](PROTOCOL.md). Пилот AOD 4 намеренно остаётся на карантине: он уже использован на этапах 4.3–4.4 и не может быть финальным независимым test. См. `pilot_manifest.json` и `pilot_stats.json`. Сами изображения/видео и веса в PR не включены.

## Что реализовано

- `python -m ml.dataset45.cli import-image` / `import-video`: EXIF-upright RGB PNG без изменения размера, для видео индекс декодированного кадра и SHA-256 исходного файла. Исходные данные и координаты не меняются. Входные подсказки сохраняются как **unreviewed**, даже если вход пытается их утвердить; импорт видео создаёт пустую разметку.
- `validate`: синтаксис, классы, размеры, границы и конечность координат xyxy, SHA файла и пикселей, размеры изображения, provenance, ошибки/предупреждения, счётчики сцен и размеров. Подозрительные рамки, пустые метки и неподтверждённые записи требуют ручной проверки; успешная валидация не гарантирует правильности меток.
- `duplicates`: точные SHA PNG или канонических пикселей, кандидаты по 64-битному dHash и средней RGB-разности. `--reference` сравнивает с известным манифестом по хешам, последовательностям и источникам. Кандидаты для человека, не автоматическое удаление.
- `visualize`: локальные PNG с рамками drone (зелёный), bird (голубой), airplane (оранжевый). Не размещать исходные изображения или отрисовки без разрешения.
- `split`: воспроизводимое группирование транзитивно по source_group, sequence_id, SHA видео, точным и вероятным дубликатам; единственная группа всегда в одной части. Пороговая разбивка групп 70/15/15 приблизительная, не стратифицирована; маленькие наборы могут не заполнить одну из частей. Перед заморозкой нужны непустые все три. Lock хранит подпись каждой записи и SHA референсных манифестов, при новых данных после freeze test не пополняется и новые связи с ним блокируются.
- `python -m ml.dataset45.evaluate`: метрики из **переданных post-NMS детекций**, не запуск модели; общий project matcher `ml/scripts/evaluate.py`, повторное вычисление по изображениям в зафиксированном split.
- `ml/tests/test_dataset45.py`: тесты на синтетике, включая импорт видео и интеграцию разбиения/оценки. Зависимости зафиксированы в `ml/requirements.txt` (включая `Pillow==13.0.0`), проверялись Python 3.13.15/Linux; сначала установить CPU torch согласно комментариям файла, затем `pip install -r ml/requirements.txt`.

## Реальный пилот

AOD 4: Vama Soni, Dhruval Shah, Jeel Joshi, DOI 10.17632/cd5z895tr2.1, https://data.mendeley.com/datasets/cd5z895tr2/1 . Карточка набора указывает CC BY 4.0, однако первичные видео/картинки могут иметь отдельные права; проверьте права каждого исходника до публикации или использования. Манifест сохраняет `origin_file`, `origin_split`, `origin_id`, SHA и выведенную последовательность предыдущего этапа, **не подтверждённую вручную**. Описания и лицензии на уровне датасета не доказывают прав на исходный медиафайл.

Детерминированно выбраны 19 конкретных записей из сохранённых 160 этапа 4.3, без отбора по результатам модели: 8 кадров с 9 drone GT; 3 с метками bird; 3 с airplane; 5 без аннотаций, с метками nature/forest/clouds/buildings/field. Из 9 рамок drone √(w×h): <16 px — 1; 16–<24 — 2; 24–<30 — 0; ≥30 — 6. Все кадры AOD 4 исходно приведены источником к 1024×1024; размер здесь — в этих пикселях, а не доказанный размер в оригинальном видео. По схеме ошибок нет; 0 кандидатов дублей внутри этих 19 не доказывает отсутствия совпадений с train. На обзорных листах просмотрены все 19, но это не полноценная ревизия разметки: сомнительная малая рамка и кадр с похожей на искусственную птицу конструкцией остаются без изменения. Ни отсутствие дронов на условных негативах, ни полная независимость от train не установлены. Все 19 `unreviewed`, `independence=unknown`, `usage_history=exposed`, `source_group_verified=false`; 0 пригодны к split. Это только проверка pipeline, не честный test и не обучающий набор.

### Воспроизведение пилота

Из корня проекта. Необходимый архив ~1.92 GB, SHA-256 `fac56b9c0494312bcd4c63dfefcbcd8ed07ab55d4b00584131c0b55273d24518`. Кадры подготавливает существующий скрипт 4.3; он использует большие локальные файлы и не следует запускать без места на диске:

```bash
export OPENBLAS_NUM_THREADS=1
python ml/scripts/independent_prepare.py --archive /path/to/AOD4.zip
# Альтернатива получения архива из документированного источника: --download
python -m ml.dataset45.aod_pilot --images ml/data/independent/images --output ml/data/dataset45-pilot/manifest.json
cmp ml/data/dataset45-pilot/manifest.json ml/results/dataset45/pilot_manifest.json
python -m ml.dataset45.cli validate --manifest ml/data/dataset45-pilot/manifest.json > ml/data/dataset45-pilot/validation.json
python -m ml.dataset45.cli duplicates --manifest ml/data/dataset45-pilot/manifest.json
python -m ml.dataset45.cli visualize --manifest ml/data/dataset45-pilot/manifest.json --out ml/data/dataset45-pilot/overlays
python -m pytest ml/tests -q
```

`aod_pilot` проверяет SHA всех четырёх сохранённых манифестов 4.3 и каждого JPEG, конвертирует COCO xywh в xyxy без исправлений и выбирает фиксированные индексы. `cmp` подтверждает соответствие опубликованному манифесту при тех же версиях зависимостей. `split` на этом пилоте должен завершиться ошибкой quarantine; не меняйте флаги, чтобы принудительно его разрешить.

## Сбор с Xiaomi 17 Pro и импорт

1. Соберите собственные видео с подтверждёнными правами: разные дроны, дистанции и фоны (небо, облака, деревья, здания), птицы, самолёты и пустые сцены; соблюдайте правила полёта, безопасность и приватность. Записывайте оригиналы без повторного пережатия, фактическое разрешение, режим и fps, место/дату и оператора в локальном журнале. Стремитесь к множеству реально размечаемых объектов 10–30 px, но не создавайте искусственные данные. На каждое видео — постоянный уникальный `sequence_id`, на независимую съёмочную сессию/общий первичный источник — общий `source_group`. Сохраняйте взаимосвязи разных клипов одной съёмки: иначе утечку нельзя предотвратить.
2. Создайте локальный `capture.json` (не публикуйте персональные сведения):

```json
{
  "source_url": "local://captures/session-001/video-001",
  "license": "owner-controlled; permission documented locally",
  "rights_note": "Confirm consent, privacy and reuse rights for each recording",
  "source_group": "session-001", "sequence_id": "video-001",
  "source_group_verified": false,
  "scene": ["sky", "trees"], "independence": "unknown",
  "usage_history": "unknown", "annotations": []
}
```

```bash
python -m ml.dataset45.cli import-video --input /path/video.mp4 --metadata capture.json --manifest ml/data/myset/manifest.json --every 90 --limit 100
# для отдельного изображения:
python -m ml.dataset45.cli import-image --input /path/photo.jpg --metadata capture.json --manifest ml/data/myset/manifest.json
python -m ml.dataset45.cli validate --manifest ml/data/myset/manifest.json
python -m ml.dataset45.cli visualize --manifest ml/data/myset/manifest.json --out ml/data/myset/overlays
python -m ml.dataset45.cli duplicates --manifest ml/data/myset/manifest.json > ml/data/myset/duplicates.json
```

`--every` — интервал в декодированных кадрах, не время; выбирайте его с учётом фактического fps и длины записи (например 90 при 30 fps ≈3 с). Время `frame_time_seconds` приблизительно `frame_index/fps` и ненадёжно при variable-frame-rate. Если decoder не поддерживает ориентацию, убедитесь визуально в upright-геометрии. Избегайте соседних почти одинаковых кадров на этапе отбора и просмотром кандидатов; после проверки вручную исключайте из *будущего* манифеста лишние кадры и ведите журнал решений. Ничего не удаляется автоматически. PNG — локальная копия: исходные оригиналы храните отдельно.

3. Размечайте canonical PNG, а не исходник с иной EXIF-ориентацией. `annotations` — список `{"class":"drone"|"bird"|"airplane", "xyxy":[x1,y1,x2,y2]}` в пикселях upright кадра, действительные числа, `0 ≤ x1 < x2 ≤ width`, аналогично y. Отмечайте каждый видимый объект отдельно, туго по видимым границам; фиксируйте неоднозначные объекты и политику искусственной птицы в журнале, передавайте спорное на вторую проверку. Пустую разметку или bird/airplane-only проверяйте на *все* возможные дроны; только после этого вручную задайте `negative_verified: true`. Псевдометки модели — лишь неподтверждённые подсказки. Проверяющий вручную задаёт `reviewer` и `review_status: "reviewed"`; исходную разметку сохраняйте неизменённой отдельно, причины правок — в журнале. `rejected` / `unreviewed` остаются в карантине.
4. До разделения подтвердите состав исходников и групп (`source_group_verified: true` только после проверки), отсутствие использования для подбора/обучения (`usage_history: "unused"`) и независимость от конкретного обучающего набора (`independence: "verified"` и `independence_evidence` с фактическими доказательствами). Если состав train неизвестен, сохранить `unknown`, не выдумывать проверку. Метки — заявления человека, код не может доказать их истинность.

## Дедупликация, разбиение и заморозка

Формат примера реальной записи — `pilot_manifest.json`; SHA и параметры рассчитываются импортёром. Создайте отдельный манифест только из проверенных допущенных записей, не включая карантин. Обработайте дубликаты до freeze и отдельно сохраните решения. Укажите **все доступные известные reference-манифесты**, заранее импортированные в тот же формат и с доступными локальными изображениями; их отсутствие не означает независимость. Эвристика: dHash расстояние ≤4 и разность среднего RGB ≤5/255. Возможны и ложные совпадения (например, небо), и пропущенные дубликаты (обрезки, преобразования, сцены из одного видео). Просмотрите конфликты и установите идентичность первичных источников; `split --reference` откажет при любых кандидатах. Внутри набора кандидаты склеиваются в одну группу, но не удаляются. На мелком наборе такая консервативная группировка может препятствовать разбиению.

```bash
python -m ml.dataset45.cli duplicates --manifest ml/data/myset/approved.json --reference ml/data/known/manifest.json
python -m ml.dataset45.cli split --manifest ml/data/myset/approved.json --reference ml/data/known/manifest.json --out ml/data/myset/prelock.json
# Проверить размеры групп, права, review и все связи, затем заморозить до подбора/тестирования:
python -m ml.dataset45.cli split --manifest ml/data/myset/approved.json --reference ml/data/known/manifest.json --lock ml/data/myset/prelock.json --out ml/data/myset/frozen.json --freeze-test
```

Пути манифестов должны находиться в соответствующих корнях с `images/`. Референсы можно не задавать только если известные данные недоступны: отметить непроверенное пересечение и не объявлять независимость. С тем же seed и полным неизменённым набором ссылочных манифестов передавайте `--lock frozen.json` при добавлении новых групп; старый lock не перезаписывать. Изменение записей, удаление, связи между разными split и присоединение к замороженному test приводят к отказу. Эти меры не обнаруживают неизвестные связи и не защищают от ручной подмены lock или просмотра test: доступ и версионирование — организационная ответственность. При найденной утечке прекратить оценку и пересоздать holdout на действительно новых независимых данных; не «чинить» уже увиденный test.
