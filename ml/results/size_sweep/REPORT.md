# Цифровая серия YOLO11s на фронтальном снимке

**Дата:** 2026-11-12. **Среда:** macOS 15.8 arm64, ONNX Runtime 1.31.1 CPU, 2 потока. Это цифровое исследование одного JPEG. Успешная дальность на Xiaomi 17 Pro по нему не оценивалась.

## Условия

- Полный `IMG_2707.jpg`, 4284 × 5712 px, [профиль `cabinet_front` в PR #34](https://github.com/Kr1st10/drone-cv-android-prototype/blob/11a6633e8827fb3c0295ceb5afb8cc5cc4b440c4/lab/monitor_test/reference_drones.js#L281-L286). SHA-256 файла `f52a6d976627d662a7622dad3cf8879363a3333744663ae3e64d533f3e474c1e`, совпадает с файлом в коммите #34.
- Использована рамка видимого коптера `[223, 1810, 4150, 2675]` в полном кадре. Её сверили визуально с JPEG. Нижнюю часть корпуса частично закрывает линейка. Рамка шириной 3927 px используется для цифрового масштаба и IoU. Измеренный отрезок моторной базы относится к другой задаче.
- Холст 640 × 640 px, фон RGB (114, 114, 114). Положения центра заданы до прогона с одинаковыми смещениями (0, 0), (+1, −1), (−2, +2) px для каждого размера. Это целочисленные сдвиги одного и того же растра относительно сетки YOLO. Дробная фаза ресемплинга отдельно не варьируется.
- RGB-фрагмент JPEG уменьшен пропорционально фильтром Pillow BOX. Ширина окна в исходнике совпадает с шириной рамки. По высоте окно симметрично расширено до ближайшей чётной высоты в пикселях вывода, чтобы центр и коэффициент масштаба были точными. Внутри фрагмента остаются контекст JPEG и часть линейки. Наименьшая рамка имеет высоту 1,76 px.
- [Проверенный ONNX](../../MODEL.md#2-экспорт-onnx) с SHA-256 `b4867481a3b3277f7b17e69b7b45077567d6929157e72dd5d48542dd34f19eb7`. Вызов штатного `DroneDetector.detect` с confidence > 0,25 и NMS 0,70. Квадратный холст проходит штатный letterbox с масштабом 1 и без полей. Совпадение с видимой рамкой фиксируется при IoU ≥ 0,50.

## Результат

В каждой строке три положения. Диапазон IoU приведён для рамок, прошедших порог confidence и NMS.

При 8 px одна из рамок получила confidence 0,531 и IoU 0,148. При 48 px рамка отсутствовала для смещения (−2, +2), при 64 px — в центре. Четыре совпадения из 21 описывают только эту серию коррелированных вариантов одного кадра. По ним нельзя оценить популяционный Recall или устойчивую минимальную ширину.

## Воспроизведение

Запускайте из корня репозитория. Подставьте путь к полному JPEG из #34. Если модели ещё нет, используйте [документированную процедуру экспорта](../../MODEL.md#2-экспорт-onnx). CLI отклонит файл с несовпадающим SHA-256. На Mac для запуска достаточно Python 3.13 с `numpy==2.5.4`, `opencv-python-headless==5.0.0.93`, `onnxruntime==1.31.1`, `Pillow==13.0.0` и `matplotlib==3.11.2`.

```sh
python ml/scripts/yolo_size_sweep.py \
  --photo /path/to/IMG_2707.jpg \
  --bbox 223 1810 4150 2675 \
  --gt-source 'PR #34 @ 11a6633, cabinet_front bounds in full IMG_2707.jpg; checked visually against visible silhouette, ruler occlusion retained' \
  --model ml/weights/yolo11s-drone-640.onnx \
  --out /path/to/new-results-directory
```

Результат включает `series.csv`, `series.json`, `size-sweep.png` и 21 точный входной растр в `inputs/`. Поля фактической ширины и высоты описывают геометрически перенесённую рамку в координатах входа. Полный список сохранённых детекций включает рамки, confidence, IoU и флаг сопоставления. Пустой список означает отсутствие кандидата после постобработки. Без `--gt-source` прямоугольник задаёт масштаб, а IoU и TP/FN/FP остаются неизвестными. Для проверенной очищенной PNG нужны собственные координаты рамки. Прозрачность компонуется на том же сером фоне.

```sh
python -m pytest -q ml/tests/test_yolo_size_sweep.py ml/tests/test_postprocess.py
```
