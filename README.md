# Drone CV Android Prototype

Университетское Android-приложение обнаруживает дроны моделью YOLO11s локально на устройстве: на выбранном фото и в видеопотоке задней камеры. Целевое устройство проекта — Xiaomi 17 Pro; совместимость конкретных объективов и качество детекции требуют испытаний на телефоне.

## Возможности и границы

- Фото: системный выбор изображения, учёт EXIF, рамки и confidence; результат сохраняется при повороте и смене вкладки.
- Камера: CameraX, запуск/остановка детекции, порог уверенности, рамки и измеренные времена обработки.
- Диагностика: экспорт JSON без кадров, сравнение 1/2/4 потоков ONNX Runtime, инвентаризация камер и запрос 1×/5×.
- Цель в видеопотоке: центр и индекс пикселя самого уверенного обнаружения текущего кадра, confidence и измерение «экспозиция → внутренний сигнал». [Границы и проверка](docs/guides/latency-and-prediction.md).
- Отдельный [лабораторный стенд](lab/monitor_test/README.md) показывает тестовые фотографии на мониторе.

Приложение определяет один класс `drone`. Каждый кадр обрабатывается независимо; трекинга и прогнозирования нет. Возможны пропуски и ложные рамки. Управление внешним устройством, БД и история распознаваний не реализованы. Инференс выполняется на телефоне.

## Требования и запуск

Для сборки нужны JDK 17, Android SDK Platform 35, Build-Tools 34.0.0 и Python 3.11+ для проверки APK. Устройство: Android 8.0+ (API 26), `arm64-v8a` или `x86_64`, задняя камера для живого режима. Gradle Wrapper включён в репозиторий.

В корне репозитория, после настройки SDK и получения проверенного ONNX в `ml/weights/yolo11s-drone-640.onnx`:

```bash
python3 ml/scripts/install_android_model.py
./gradlew --no-daemon assembleDebug testDebugUnitTest
python3 ml/scripts/verify_apk_model.py app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug
adb shell am start -n ru.university.dronecv/.MainActivity
```

Модель не входит в Git. Источник готового файла, настройка JDK/SDK и ожидаемые результаты команд описаны в [быстром старте](docs/getting-started.md). На телефоне должны открыться вкладки «Фото» и «Камера»; после выдачи разрешения камеры должно появиться превью. Наличие рамки на произвольной сцене не служит критерием успешного запуска.
