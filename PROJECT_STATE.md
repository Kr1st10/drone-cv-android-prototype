## Реализовано
- Режимы «Фото» и «Камера». Прежний CameraX preview не изменён, permission CAMERA запрашивается только в режиме камеры.
- Photo Picker без разрешения на всю галерею; отмена выбора сохраняет снимок/результаты.
- Фоновая загрузка upright sRGB Bitmap, до 2048 px по длинной стороне, EXIF-повороты/отражения; API 26/27 — subsampling + ExifInterface, API 28+ — ImageDecoder. Прозрачность композитится на чёрный фон.
- Ручной запуск существующей локальной YOLO11s: реальные рамки, confidence, номера и время ORT-инференса. Общая геометрия Fit для фото и рамок; без crop.
- Состояния loading/ready/running/detections/empty/error, повторный запуск и выбор другого снимка во время обработки. Один worker, одна заменяемая ожидающая команда, generation-проверки результатов/ошибок.
- Activity ViewModel сохраняет состояние при повороте/смене режима. Закрытие освобождает ORT после нативного вызова вне UI; временные Bitmap утилизируются, опубликованные снимаются со ссылок для безопасного GC.
- CI собирает app и AndroidTest APK, запускает unit-тесты/lint и прежние проверки модели. README, AGENTS.md и [чек-лист телефона](docs/PHOTO_QA.md) обновлены.
