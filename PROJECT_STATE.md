- Интерфейс `ObjectDetector` — **только контракт, реализаций нет**.
- README с инструкцией сборки; workflow GitHub Actions `assembleDebug`.

## Известные ошибки и ограничения
- `gradle/wrapper/gradle-wrapper.jar` отсутствует в репозитории → `./gradlew` не работает до `gradle wrapper`. CI от jar не зависит (использует `setup-gradle`).
- Нет выбора камеры, зума, фокуса. Ориентация не зафиксирована: при повороте Activity пересоздаётся и камера перепривязывается.
- Поведение на Xiaomi 17 Pro не проверялось.
