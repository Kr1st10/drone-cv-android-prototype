# Один поворот DJI по рамке YOLO

Пробный канал для разработчика стенда. Debug-приложение на vivo отправляет один запрос по TCP через Wi-Fi ADB reverse. Mac вызывает существующую команду `dji-rs-probe nudge`, которая запрашивает один относительный поворот по yaw на +3° за 1 с. Сетевой ответ содержит результат и измеренные углы. Это не контур повторного наведения: vivo находится в руках, iPhone поворачивается вместе с DJI.

## Условия и знак

Используйте неподвижное фото справа от центра кадра обеих камер. Для проверенной установки iPhone положительный yaw сдвигал цель влево. Поэтому направление `right` преобразуется в `yaw positive`. Основание: ручные прогоны WeAct от 2026-11-23 в локальном `PROJECT_STATE.md` ветки `codex/dji-rs-weact-transport`. При другой ориентации крепления это соответствие нужно проверить заново до автоматического запуска.

На vivo разрешён только режим A: YOLO. Предел возраста 2500 мс задан специально для этого опыта: ранее медиана экспозиция → публикация составляла 1370,9 мс, максимум 1575,2 мс. Возраст измеряет Android по `elapsedRealtimeNanos`, перед отправкой. Mac проверяет переданный возраст, но не вычитает часы Android из собственных часов. Предел относится к допуску запроса, не гарантирует завершение механического поворота за 2500 мс. Для повторных коррекций изображение приложения должно приходить с камеры, закреплённой на DJI.

## Подготовить Mac

Из корня рабочей копии:

```bash
./gradlew -p lab/dji_rs_probe test installDist
python3 -m unittest discover -s lab/one_turn_bridge -p 'test_*.py' -v
```

Mac-модуль скопирован из проверенной локальной WeAct-утилиты: `GimbalNudge`, транспорт, SLCAN и кодеки сохранены. Здесь кодеки находятся внутри `lab/dji_rs_probe/src`, поэтому эксперимент не добавляет управление DJI в штатный Android backend. Новая последовательность команд движения не реализуется.

Проверьте текущий ADB serial и порт WeAct:

```bash
adb devices -l
ls /dev/cu.usbmodem*
adb -s ANDROID_WIFI_SERIAL reverse tcp:18765 tcp:18765
adb -s ANDROID_WIFI_SERIAL reverse --list
```

`ANDROID_WIFI_SERIAL` замените на адрес из `adb devices`, например с портом беспроводной отладки. Туннель действует для выбранного устройства и может пропасть после переподключения. На Mac сервер слушает только `127.0.0.1`, не локальную сеть. Для APK и сервера нужен одинаковый случайный токен; реальный токен и журналы не коммитьте. Android использует локальную конфигурацию сборки `oneTurn.token`, сервер читает такой же токен из отдельного файла.

```bash
python3 lab/one_turn_bridge/bridge.py \
  --token-file /private/tmp/one-turn-token.txt \
  --journal /private/tmp/one-turn-attempt.ndjson \
  --probe lab/dji_rs_probe/build/install/dji-rs-probe/bin/dji-rs-probe \
  --weact-port /dev/cu.usbmodemYOUR_ADAPTER
```

По умолчанию сервер допускает одну попытку движения за журнал. Для следующего отдельного опыта остановите сервер и задайте новый путь журнала. `--max-attempts N` допускает N разных нажатий с разными кадрами в одном журнале; автоматических повторов нет. После неизвестного исхода тайм-аута сначала проверьте фактическое положение DJI. Не используйте новый журнал как автоматическую повторную отправку старой команды.

## Протокол TCP

Один запрос и один ответ на соединение, JSON UTF-8 с завершающим LF. Запрос ограничен 4096 байтами, сокет при чтении запроса ждёт не более 3 с. Поля:

| Поле | Контракт |
| --- | --- |
| `schema` | Целое `1`. |
| `token` | Токен локальной тестовой сборки. Не пишется в журнал. |
| `attempt_id` | UUID нового нажатия, каноническая строка. |
| `frame_id`, `source_id` | Целые идентификаторы кадра и источника. |
| `capture_ns`, `armed_ns` | Десятичные строки Android elapsed realtime; `capture_ns > armed_ns > 0`. |
| `age_ms` | Возраст кадра при отправке, конечное число от 0 до 2500. |
| `offset_x`, `width` | Смещение центра рамки в пикселях от `width / 2`; положительное означает вправо. |
| `direction` | Только `right`, при `offset_x / width > 0.1`. |

Подставные примеры применяются только в тестах. Реальный сервер не получает синтетических CV-сигналов для аппаратной приёмки.

Ответ: `attempt_id`, `frame_id` для принятой попытки, `status`, `message`, `yaw_before`, `yaw_after`. `status` принимает `success`, `error`, `timeout`, `rejected`. `yaw_after` использует последний стабилизированный замер, если он получен. При отсутствии углов значение `null`; подтверждение команды без проверки изменения угла не считается успехом.

## Одноразовость и журнал

Сервер проверяет токен, время, геометрию и направление до обращения к WeAct. Рамка в центре, слева, отсутствие цели или устаревший кадр не расходуют допуск движения. Для принятой попытки сервер синхронно пишет `attempt_reserved` с ID кадра, смещением и направлением и выполняет `fsync` до запуска `nudge`. Дубликат UUID либо кадра не запускает транспорт. Пока выполняется попытка, другой UUID отклоняется. Файл журнала блокируется от второго процесса.

`attempt_result` сохраняет stdout/stderr `nudge`, код завершения, углы `before`, `after`, `settled`. Утилита выполняется один раз с общим пределом 10 с. После ошибки, тайм-аута или отключения Android запрос не повторяется. При перезапуске сервера ранее зарезервированные UUID и кадры читаются из того же журнала и остаются израсходованными. Токен в журнал не записывается.

## Проверки и физическая приёмка

Подставной транспорт проверяет один запрос положительного yaw, центр/лево/отсутствие цели, старый кадр, дубликат, тайм-аут, повтор после перезапуска, занятый транспорт и реальный loopback-сокет без оборудования. Проверки существующей Mac-утилиты отдельно подтверждают, что `nudge` отправляет одну позиционную команду и не повторяет её без ответа.

Для физической приёмки запишите диагностику Android и один Mac-журнал. После нажатия «Разрешить один поворот» используйте свежий реальный кадр справа. Успех требует: один запрос от приложения, `nudge_pass`, yaw изменился в ожидаемую сторону, фото в кадре iPhone приблизилось к центру. Последний пункт подтверждается реальным наблюдением оператора или записью iPhone; углы сами по себе этого не доказывают. В итоговом отчёте отделяйте эти испытания от подставных тестов и компиляции APK.
