# Состояние эксперимента с эквивалентной дальностью

Обновлено: 2026-11-06. База: `main` @ `684d780`. Ветка: `codex/monitor-equivalent-range`.

- Существующие расстояние, зум 1×/5×, калибровка k, px кадра и confidence используются повторно. В форме R расширенного режима добавлены реальная ширина аппарата, источник габарита/границы ширины и измеренная ширина изображения на мониторе. Величины не переходят на другое изображение/уровень; отрицательные и нулевые размеры отклоняются.
- Эквивалентная дальность рассчитывается по отношению одинаковых физических ширин, угловая ширина — по геометрии экран/камера. Нет обязательного измерения — null; приблизительные мм по рамке не используются. Новые поля добавлены в CSV/JSON без изменения формата сессии и ключей браузера. Старый импорт/localStorage дополняются null, вычисляемые данные пересчитываются из исходных.
- Сводка в S и JSON `size_summary`: по прогону, типу drone/negative, источнику и размеру в px (округление 0,1) — число проверок, TP/доля, отдельно FP/доля негативов, min/max эквивалентной дальности и число известных значений. Контрольный уровень пустого фона не выдаётся за измеренный размер.
- [Протокол](PROTOCOL.md#короткий-эксперимент-для-10-дюймового-коптера-1-и-5) задаёт фиксированные условия, порог 50 %, окно 10 с, повтор калибровки для 5× и три повторных прогона каждого режима. Обнаружение за окно не является метрикой устойчивости по кадрам.
- Локальные проверки: **13 passed**, включая Playwright в Google Chrome, проверку `60 см / 150 см / 60 мм → 15 м`, неизвестные/некорректные значения, CSV/JSON, новые и старые сессии, повтор 1×/5× и сводку. Валидатор: `manifest OK: 90 images`. JavaScript syntax и `git diff --check` — без ошибок; локальные ссылки README/PROTOCOL проверены. Данные тестов синтетические, не результаты CV. Форму и сводку проверили по скриншотам браузера.
- Изменения ограничены этой папкой. Корневой PROJECT_STATE и другие файлы PR #24 намеренно не менялись по условию задачи; запись состояния находится здесь. Android/ONNX/веса, исследования и изображения не изменялись; Android-сборки не запускались.
- Не подтверждены физические измерения монитора/телефона, точность калибровки, реальные detection/confidence, порог уверенного обнаружения, полевая дальность и наличие снимка конкретного 10″ аппарата с известным габаритом. Следующий шаг — оператор выбирает/подтверждает подходящую модель и фотографию, выполняет серию 1×/5× и прикладывает реальные экспорты с условиями. Если подходящего снимка нет, его включение в манифест требует отдельной подготовки данных.
