# Пилот YOLO на неподвижной фотографии

Откройте [анализатор](index.html) в браузере. Он работает локально, включая открытие с диска. Для показа фотографии и задания эквивалентной дальности используйте [лабораторный стенд](../gallery.html). Запишите название эталона и фото, ракурс, фактическую эквивалентную дальность по калиброванной геометрии, расстояние до экрана, фон, устройство и камеру с зумом. Положение телефона, фотографию, масштаб, фон и порог держите постоянными.

1. На Android выберите режим «YOLO». После стабилизации заранее задайте начало серии, в секундах от старта диагностики. Если условия выставлены до записи, оставьте 0. Запустите диагностику и дождитесь окончания показа. При медленном детекторе набор 20 кадров может занять больше 20 секунд.
2. Выгрузите **диагностический отчёт** Android, выберите его на странице и внесите условия. Порог берётся из `model.confidence`. При отсутствии поля можно внести известный порог вручную, с указанием источника в экспорте.
3. Проверьте число отобранных кадров и выгрузите CSV или JSON. Отчёт диагностики сохраните отдельно.

## Правило отбора

В корневой схеме `schema_version=1` Android записывает в `frames[]` завершённые актуальные вызовы детектора, включая длительности пяти стадий. В режиме «YOLO» `target_signal` v2 содержит исход `detected` / `no_target`, идентификаторы источника и публикации, время входа исходного кадра в анализатор и confidence выбранного кандидата. Временная метка таблицы — `offset_ms` от начала записи **до завершения** YOLO. Для выбора сначала используется порядок по этой метке, при равенстве — порядок строк файла. Берётся первая пригодная строка с указанного начала, затем первая пригодная строка с завершением не ранее чем через 1000 мс после предыдущей отобранной. Отбор ограничен 20 строками и одним источником камеры.

Для исключения повторов сравниваются идентификатор публикации, время входа кадра и доступная метка экспозиции в рамках одного источника. Повторы исключаются и в случае, когда первое появление пришлось на интервал между отобранными кадрами или было до начала серии. Результат и confidence не влияют на порядок. Отклонённые и отменённые вызовы Android не записывает в ряд завершений. Записи `tracking.samples` и повторно используемый в них `last_yolo_confidence` не участвуют. Строки только с `detection_count` из режима сопровождения показывают наличие кандидата, но не имеют метки исходного кадра и не подходят для этой серии. Старые версии сигнала, отчёты только с таймингами, журналы A/B и NDJSON временной шкалы лежат за пределами поддерживаемого входа. Формат диагностики описан в [модели данных Android](../../../docs/reference/data-model.md#json-производительности-schema_version-1).

## Интерпретация и экспорт

В знаменатель входят только отобранные завершения с известным исходом. Доля равна числу кадров с кандидатом, делённому на число проверенных кадров. Для пустой серии она неизвестна. Кадры одной видеосессии коррелированы даже при секундном интервале. Импорт в «Измерить предел» по-прежнему означает одну подтверждаемую оператором проверку на файл.

Для автоматических TP/FN/FP нужны идентификатор исходного кадра, сам кадр или проверяемая ссылка на него, проверенная разметка присутствия/отсутствия цели и всех целевых объектов, полный список рамок YOLO с классами и confidence, включая явно пустой список, а также размеры и система координат кадра. Тогда можно сопоставить рамки один к одному по заранее заданному критерию, например порогу IoU. Диагностика v2 хранит центр кандидата, поэтому для текущего входа TP/FN/FP, подтверждённый Recall и успешная дальность остаются недоступны.

В JSON `dronecv-yolo-pilot-1` есть сведения об исходном файле, условия, правило отбора, сводка, причины ограничения GT и список попыток. Confidence и доля записаны в шкале 0–1. CSV повторяет общие поля в каждой строке. Для пустой серии в CSV остаётся одна строка с условиями и сводкой, поле `attempt` пустое. Неизвестные значения записываются как `null` в JSON и пустые ячейки в CSV. JSON содержит исходный текст полей. CSV нейтрализует ввод, который электронная таблица может выполнить как формулу.
