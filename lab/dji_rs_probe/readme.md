# Проверка DJI RS 5 через WeAct на Mac

Утилита предназначена для разработчика и тестировщика. Она читает версию USB–CAN WeAct USB2CANFDV1, запрашивает углы и проверяет разовый поворот по DJI RS SDK. Android, модель YOLO и телефон для сборки и запуска не нужны.

## Сборка и проверка USB

Нужны JDK 17, macOS для реального порта и доступ Gradle к зависимостям при первой сборке. Запустите из корня репозитория:

```bash
./gradlew -p lab/dji_rs_probe test installDist
WEACT_PROBE=lab/dji_rs_probe/build/install/dji-rs-probe/bin/dji-rs-probe
"$WEACT_PROBE" --help
```

Подключите только адаптер по USB. Найдите его порт в выводе `ls /dev/cu.usbmodem*`, подставьте этот путь вместо примера и выполните:

```bash
WEACT_PORT=/dev/cu.usbmodemYOUR_ADAPTER
"$WEACT_PROBE" adapter-info --port "$WEACT_PORT"
```

Успех — строка вида `WeAct Studio V1.0.0.3_bb264e71`. Режим отправляет только запрос версии `V` с символом CR. Настройки и канал CAN он не меняет. Если порт отсутствует или занят, проверьте USB и закройте программу, которая его использует. Если порт открывается, но строка версии не приходит, проверьте, что на адаптере прошивка WeAct в режиме SLCAN. [Протокол WeAct](https://github.com/WeActStudio/WeActStudio.USB2CANFDV1#slcan-protocol-description).

На прошивке WeAct `V1.0.0.3_bb264e71` настройка `H0` может вернуть отказ. Утилита продолжает в текстовом режиме после явного отказа на эту необязательную команду. Для установки обычного режима, скорости и открытия CAN требуется подтверждение. [Команды SLCAN WeAct](https://github.com/WeActStudio/WeActStudio.USB2CANFDV1#slcan-protocol-description).

## Проверка с подвесом

Для этого этапа нужны RS 5, совместимый кабель к RSA/NATO и подтверждённые параметры CAN для конкретного подключения. [Страница DJI подтверждает поддержку RS SDK](https://www.dji.com/rs-sdk), а опубликованная там схема подключения и параметры шины в спецификации относятся к RS 2. В примере для RS 2 со стороны компьютера указаны 1 Мбит/с, TX `0x223` и RX `0x222`. Два запроса чтения углов на проверенной связке RS 5 и WeAct `V1.0.0.3_bb264e71` подтвердили эти параметры. Для другого подключения подтвердите профиль отдельно.

Заполните `WEACT_CAN_BITRATE`, `WEACT_CAN_TX_ID` и `WEACT_CAN_RX_ID` проверенными значениями, только если RS SDK передаётся последовательными фрагментами в кадрах классического CAN. Команда отправит один запрос чтения углов:

```bash
"$WEACT_PROBE" read-attitude --port "$WEACT_PORT" --profile sdk-classic-stream \
  --can-bitrate "$WEACT_CAN_BITRATE" --tx-id "$WEACT_CAN_TX_ID" --rx-id "$WEACT_CAN_RX_ID"
```

- `--profile sdk-classic-stream`: кадры классического CAN с 11-битным ID, до 8 байт данных. Фрагменты одного SDK-пакета идут подряд без дополнительного заголовка фрагмента. Этот способ упаковки проверен на подставном порту и при чтении углов с RS 5.
- `--can-bitrate`: скорость CAN в бит/с. Поддерживаются 5000, 10000, 20000, 50000, 75000, 100000, 125000, 250000, 500000, 800000 и 1000000. Скорость последовательного USB-порта настраивается отдельно и равна 115200 бод.
- `--tx-id` и `--rx-id`: разные идентификаторы отправки и приёма, десятичные или шестнадцатеричные с префиксом `0x`.
- `--timeout-ms`: от 1 до 10000 мс, по умолчанию 2000. Один бюджет на открытие CAN-канала, один на отправку всего запроса, один на ожидание ответа и один на закрытие канала. Следующий фрагмент не продлевает бюджет своего этапа.

Инструмент выводит `seq`, события обмена и результат. Углы дают код завершения 0. Ошибка обмена, недействительный ответ, отсутствие углов или тайм-аут дают 1; неверные параметры — 2. Подтверждение SLCAN от WeAct не заменяет ответ DJI. Для приёмки сохраните два корректных ответа: до и после ручного поворота джойстиком. Проверьте изменение угла нужной оси.

## Пробный поворот

Переходите к повороту после двух успешных чтений с RS 5. Закрепите и сбалансируйте телефон с держателем при выключенном подвесе или в режиме сна. Поставьте подвес на устойчивую опору, освободите ход осей и оставьте кабелю запас длины. Кнопка питания RS 5 переводит подвес в режим сна одним нажатием. [Руководство DJI RS 5, разделы 2.3 и 3.1](https://dl.djicdn.com/downloads/DJI_RS_5/20260115/UM_2/DJI_RS_5_User_Manual_en.pdf).

Из корня репозитория выполните один шаг по горизонтальной оси с теми же параметрами, что использовали при чтении:

```bash
"$WEACT_PROBE" nudge --port "$WEACT_PORT" --profile sdk-classic-stream \
  --can-bitrate "$WEACT_CAN_BITRATE" --tx-id "$WEACT_CAN_TX_ID" --rx-id "$WEACT_CAN_RX_ID" \
  --axis yaw --direction positive
```

`--axis pitch` выбирает наклон, `--direction negative` меняет знак. Сопоставьте знак SDK с перемещением телефона и рамки на стенде. Один запуск запрашивает относительный шаг 3° по одной оси за 1 с. При сбое или тайм-ауте проверьте положение подвеса перед повторным запуском. Утилита отправляет команду движения один раз. [DJI RS SDK v2.5, раздел 2.3.4.1](https://www.dji.com/rs-sdk).

| Вывод | Что проверено |
| --- | --- |
| `before` | Подвес ответил углами до поворота. |
| `position_ack` | Подвес ответил на позиционную команду с кодом 0. |
| `after`, `settled` | Получены два набора углов после команды с паузой 350 мс между чтениями. |
| `delta_deg`, `drift_deg` | Изменение углов от исходного положения и разница между двумя последними замерами. |
| `nudge_pass` | Выбранная ось сместилась на заданный угол с допуском 1°, прочие оси изменились не более чем на 1°, два последних замера различаются не более чем на 0,5° по каждой оси. |

Код завершения 0 означает успех. При сбое обмена или выходе угла за допуск утилита завершится с кодом 1 и напечатает причину. Сохраните вывод для `yaw` и `pitch`, а также наблюдаемое направление физического поворота. Для сопоставления с приложением на установленном телефоне включите сухой прогон. Покажите камере неподвижную цель на мониторе и отметьте, куда сместилась рамка после каждого поворота. [Сухой прогон в PR №62](https://github.com/Kr1st10/drone-cv-android-prototype/pull/62).

## Что проверяют тесты

Сценарии на JVM используют те же кодек, считыватель и SLCAN-транспорт, что и [debug-диагностика Android](../../docs/guides/read-dji-attitude-vivo.md). Подставной порт выдаёт строки SLCAN частями, позволяет получить ответ до последнего подтверждения отправки и имитирует тайм-аут, отказ WeAct и отключение. Для поворота проверены байты запроса обеих осей, ответы с чужим номером, запрет повторной отправки и контроль фактического изменения углов. CAN-кадры при этих тестах не посылаются на реальное оборудование. [Контракт чтения DJI](../../docs/reference/api.md#прямое-чтение-углов-dji).
